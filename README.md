# Jessica DeLozier — Professional Portfolio

Technical Product, Program, and Data Platform Leadership.

Live site: https://jkdelozier.github.io/ProfessionalPortfolio/

Plain HTML and CSS. Edit index.html for portfolio content, resume.html for the printable résumé, and styles.css for design. Native case-study disclosures support keyboard interaction. EB Garamond is served by Google Fonts, with Garamond and Georgia fallbacks. No JavaScript or build step.
